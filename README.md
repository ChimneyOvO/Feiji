# 飞记 (FeiJi) - 飞书待办智能识别与看板应用

**飞记** 是一款专为 Windows 用户设计的现代化桌面待办管理助手。通过 Windows UI Automation 本地观察飞书聊天界面，自动提取待办关键词与中文截止时间，无缝归集入任务看板并进行定时到期提醒。

---

## ✨ 核心特性

1. **飞书界面文本智能捕获**
   - 采用 Windows UI Automation 本地无障碍树监听，无需申请飞书开放平台开发者权限，开箱即用。
   - 内置 MD5 消息去重机制，防止重复录入。
   - 提供启停监听开关及便捷的“模拟飞书消息”测试弹窗。

2. **中文自然语言截止时间识别**
   - 自动识别口语化中文相对/绝对时间：
     - `今天下午3点前`、`今晚8点`、`下班前`
     - `明天上午10:30`、`后天18点`、`大后天`
     - `本周五下班前`、`下周一上午9点`
     - `2小时后`、`半小时后`、`3天后`
     - `9月15日14点`
   - 自动将时间转换为精准绝对时间戳并计算倒计时。

3. **现代 Fluent 任务看板**
   - 三列状态看板：**待处理**、**进行中**、**已完成**。
   - 任务卡片展示：任务摘要、来源原对话、截止时间倒计时标签（超时红字高亮、临近橙色预警）。
   - 顶部实时统计：完成进度百分比与进度指示条。
   - 支持快捷搜索、手动新建、编辑、删除任务。

4. **到期与预警提醒机制**
   - **轻度模式**：仅在截止时刻推送一次通知。
   - **中度模式**：提前预警（默认提前15分钟）+ 到期提醒。
   - **强力催促模式**：提前预警 + 到期提醒 + 超时后每隔 X 分钟（默认10分钟）持续催促，直到任务标记完成。
   - 支持 Windows 原生系统托盘气泡与应用内通知横幅。

5. **系统级集成与设置中心**
   - **关键词管理**：自由添加、删除、启用/禁用待办触发词（如 `帮忙`、`辛苦`、`TODO`、`排期` 等）。
   - **提醒强度调节**：自定义提前预警时间（1~120分钟）与循环催促频率。
   - **外观个性化**：支持深色模式、浅色模式、跟随系统，以及 5 种 Fluent 主题色切换。
   - **开机自启动**：一键开启/关闭 Windows 注册表开机启动。
   - **后台驻留**：关闭窗口自动最小化至 Windows 系统托盘，后台持续监听。

## 🚀 快速启动

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行应用
```bash
python run.py
```

### 3. 运行测试
```bash
python -m unittest discover tests
```

### 4. 重新打包可执行文件与安装包
```bash
python build_package.py
```
打包生成文件均位于 `dist/` 目录下：
- **`dist/FeiJi.exe`**：单文件绿色独立可执行文件，双击即用，免 Python 环境。
- **`dist/FeiJi_Setup_v1.0.0/`**：安装包目录（包含一键安装与桌面图标生成脚本）。
- **`dist/FeiJi_v1.0.0_Setup_x64.zip`**：便携式发布压缩包。

---

## 📦 安装与分发

- **免安装便携版**：直接运行 `dist/FeiJi.exe`。
- **快捷安装版**：进入 `dist/FeiJi_Setup_v1.0.0/` 文件夹，双击运行 **【安装飞记(创建桌面快捷方式).bat】**，将自动在桌面与开始菜单创建“飞记”应用图标并完成部署。
- **一键卸载**：运行 `dist/FeiJi_Setup_v1.0.0/卸载飞记.bat` 即可一键彻底清理。

## 📂 项目结构

```
dist/                     # 打包输出产物目录 (EXE、安装包、ZIP)
feiji/
├── core/
│   ├── database.py       # SQLite 数据库与 CRUD (任务、关键词、设置)
│   ├── monitor.py        # 飞书 UI Automation 监听与去重引擎
│   ├── parser.py         # 中文自然语言时间提取与关键词匹配
│   ├── reminder.py       # 定时预警与到期提醒调度器
│   └── autostart.py      # Windows 注册表开机自启管理
├── ui/
│   ├── main_window.py    # Fluent 侧边栏主窗口与系统托盘管理
│   ├── board_view.py     # 任务看板、完成进度条与顶部工具栏
│   ├── kanban_column.py  # 看板单列组件 (待办/进行中/已完成)
│   ├── task_card.py      # 任务卡片组件 (倒计时、原对话、流转按钮)
│   ├── task_dialog.py    # 任务手动新建/编辑弹窗 (含快捷时间选择)
│   └── settings_view.py  # 设置页面 (关键词/提醒频率/主题色/自启动)
├── main.py               # 应用程序入口
tests/                    # 单元测试与端到端集成测试
build_package.py          # 自动化打包与安装包构建脚本
make_icon.py              # 高清应用图标生成脚本
feiji.ico                 # 256x256 高清多分辨率应用图标
requirements.txt          # Python 依赖清单
run.py                    # 根目录启动脚本
```
